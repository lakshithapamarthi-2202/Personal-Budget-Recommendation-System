# Personal Budget Recommendation System

A machine learning project that analyzes personal expenses and provides budget recommendations.

## About the Project

This project uses expense-related data to analyze spending patterns and provide recommendations for better budget management.

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Tkinter
- Excel

## Features

- Expense analysis
- Budget recommendations
- Expense prediction
- Data visualization
- User-friendly interface

## Machine Learning

The project uses a Decision Tree Regression model to analyze expense data and predict total expenses.
